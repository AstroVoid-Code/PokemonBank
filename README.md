Pokémon Bank

Simulador de cajero automático desarrollado como proyecto web utilizando HTML, CSS, JavaScript, Bootstrap y Chart.js.

Descripción

Pokémon Bank es una aplicación web que simula las operaciones principales de un cajero automático.

El sistema permite al usuario ingresar mediante un PIN y realizar diferentes operaciones bancarias desde un menú principal.

Funcionalidades

- Inicio de sesión mediante PIN.
- Depósito de dinero.
- Retiro de dinero.
- Consulta de saldo disponible.
- Pago de servicios.
- Historial de transacciones.
- Gráfico de transacciones realizadas.
- Actualización automática del saldo después de cada operación.
- Almacenamiento de datos utilizando LocalStorage.

Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 4
- Chart.js
- LocalStorage
- Git
- GitHub

Flujo del sistema

Inicio de sesión → Menú principal → Selección de operación

Desde el menú principal el usuario puede acceder a:

- Depositar
- Retirar
- Consultar saldo
- Pagar servicios
- Consultar historial
- Visualizar gráficos

Cada operación actualiza la información almacenada en el navegador.

Saldo inicial
